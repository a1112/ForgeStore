## 实际 GUI 流程

两个代次分别打开中文名 UTF-8/LF 输入文件，保留已有中文内容，普通替换 `BEFORE` 为 `AFTER`，追加不同 ASCII 行。通过 GUI Save As 分别写入 ASCII 路径 TXT 和 OpenDocument Text。正常退出后启动新正式进程，显式打开两个输出并观察实际内容。

| 代次 | 输入 | TXT 输出 | ODT 输出 |
| --- | ---: | ---: | ---: |
| 正式原代次 | 75 字节 | 103 字节 | 1,341 字节 |
| 独立市场代次 | 85 字节 | 111 字节 | 1,347 字节 |
